# Project Context

## Purpose
Creating a writing assistance application with Electron and React that can run custom prompts on selected text by hitting a shortcut key. Prompts are chosen with buttons. Another option is to open a chat to ask LLM. At start, use Ollama as the only provider.

## Tech Stack
- Electron
- React
- TypeScript
- ESLint
- Jest
- Tailwind CSS

### Code Style

### Testing Strategy
Use TDD (Test-Driven Development)

Use GitHub workflow
